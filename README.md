# Focus Player

A distraction-free YouTube learning player for homeschool families and diverse learners.

## Live App
https://focusplayermvp.netlify.app

## What it does
- Curator builds lessons from YouTube videos with specific clips
- Learner watches in a distraction-free environment
- Thought capture on pause — curiosity becomes curriculum
- Notes saved with timestamps, synced to Supabase
- Profiles for multiple family members with Curator and Learner roles

## Tech Stack
- Single HTML file (index.html)
- YouTube IFrame API via youtube-nocookie.com
- Supabase for cloud data storage
- Web Speech API for voice notes

## Run Locally
cd ~/Documents/focus-player
python3 -m http.server 8000
Open http://localhost:8000
